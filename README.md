- ⚖️ Feature comparison table
- ⭐ Customer reviews section
- 🛍️ Related accessories
- 🧭 Scroll-aware navigation

| Category | Technology |
|---|---|
| Markup | HTML5 |

| Interactivity | JavaScript |

## 🚀 Getting Started

### Installation

```bash
# Clone the repository
git clone https://github.com/Mahmoudahmed992005/DJI-MAVIC-4-pro.git

# Navigate into the project
cd DJI-MAVIC-4-pro
```

### Run

No build step required — just open `index.html` directly in your browser, or serve it with a live server:

```bash
# Using VS Code Live Server extension, or:
npx serve .
```
